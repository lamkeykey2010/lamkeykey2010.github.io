# Widget Shuffle homepage

The domain homepage at https://lamkeykey2010.github.io/ introduces Widget Shuffle and links to its existing project website at https://lamkeykey2010.github.io/widget-shuffle/.

`public/index.html` contains the Google AdSense verification meta tag for `ca-pub-8094200952197851`. No ad loader, ad unit or analytics is installed. Site verification and review do not guarantee approval or ad serving.

`public/ads.txt` publishes the supplied Google seller authorization at https://lamkeykey2010.github.io/ads.txt. The meta tag verifies ownership, while ads.txt identifies the authorized advertising seller. Google updates their statuses separately and may take time to recrawl the file.

Push to `main` to deploy `public/` through GitHub Actions. This repository does not change the game repository, URL, or saved progress.
